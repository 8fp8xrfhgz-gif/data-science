# California Housing Price Prediction

End-to-end supervised ML project predicting median house values using a random forest regression model, based on 1990 California census data.

## Highlights
- Data cleaning: median imputation, one-hot encoding, feature engineering, feature scaling
- Model: Random Forest (500 trees), train/test RMSE approximately 49K
- Key finding: median_income is the strongest predictor of house value

## Files
- ClassProject_YunChiehChen.R - full R script
- Class_Project_Report.pdf - full project report

## Skills
R, randomForest, data munging, EDA, feature engineering, regression modeling

- housing.csv - California housing dataset (1990 census), 20,640 rows
