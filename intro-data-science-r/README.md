# Introduction to Data Science (R Coursework, UCLA Extension)

Coursework from **Introduction to Data Science** (COM SCI X450.1), UCLA Extension, taught by Prof. Gutierrez. All analysis done in R.

## Contents

- **`hw1_r_fundamentals.R`** — R fundamentals: matrices, lists, factors, `table()`, `subset()`, loops, `apply()` family functions, random sampling, and date/time handling.

- **`hw2_sql_data_reshaping.R`** — More advanced data manipulation:
  - SQL querying within R using `sqldf`
  - Data reshaping with `melt()` (wide-to-long format)
  - Grouped operations with `split()` + `sapply()`, and `dplyr`
  - Visualization: 3D scatter plots, histograms, box plots

## Why this matters for my current work

This course runs in parallel with my Data Science Fundamentals program (which focuses on Python), giving me exposure to the same core data science workflow — data manipulation, querying, and visualization — in a second language (R). Being comfortable in both Python and R is valuable heading into an MSDS program, where coursework often uses both.
