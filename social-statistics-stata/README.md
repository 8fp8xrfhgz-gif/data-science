# Social Statistics (Stata Coursework, NTU)

Coursework from **Social Statistics**, National Taiwan University. All analysis done in Stata.

## Contents

- **`hw1_descriptive_stats.do`** — Homework 1. Data import/cleaning (importing Excel data, saving as `.dta`), descriptive statistics (`sum ... detail`), and sorting/ranking analysis.

- **`hw3_hypothesis_testing.do`** — Lab assignment 3, using the Taiwan Social Change Survey (TSCS 2021). Covers confidence intervals, one-sample hypothesis testing (z-test, t-test, proportion test), and two-sample hypothesis testing (independent and paired samples) — each with explicit null/alternative hypotheses and interpretation of p-values.

## Why this matters for my current work

This course built my foundation in formal statistical inference — writing out hypotheses, choosing the right test, and correctly interpreting p-values and confidence intervals. That same framework underlies how I evaluate models and interpret coefficients in my current data science coursework.

**Note:** The `tscs2021q2_with_age.dta` dataset (Taiwan Social Change Survey) is not included here due to file size; it is publicly available through Academia Sinica's Survey Research Data Archive.
